# uBiddrazzu


## Descrizione
**uBiddrazzu** (uB o µB) è un motore scacchistico realizzato a fini didattici da programmatori amatoriali.


## Utilizzo
Per usare uB bisogna prima clonare il reposiory e compilare il file main.c presente nella cartella `src`.

**NOTA**  uB usa funzioni C (come `_pext_u64()`) che sono state adottate relativamente da poco dallo standard del linguaggio. Proprio per questo motivo, **il motore non è supportato dai processori Intel precedenti al 2013 e dai processori AMD precedenti al 2020**.
Inoltre, **il motore non supporta i sistemi operativi macOS e Linux** (al momento) perché è stato sviluppato usando delle funzioni integrate del compilatore e sfruttando l'ambiente Windows.
