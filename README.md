# uBiddrazzu

## Descrizione
**uBiddrazzu** (uB o µB) è un motore scacchistico realizzato a fini didattici da programmatori amatoriali.

## Utilizzo
Per usare uB bisogna prima clonare il reposiory e compilare il file CMake.
`git clone https://github.com/computerpapi/uBiddrazzu`
Successivamente, non resta che eseguire il file CMake da VS Code ed è fatta!

**NOTA**  uB usa funzioni C (come `_pext_u64()`) che sono state introdotte e adottate relativamente da poco dallo standard del linguaggio. Proprio per questo motivo, **il motore non è supportato dai processori Intel precedenti al 2013 e dai processori AMD precedenti al 2020**.
